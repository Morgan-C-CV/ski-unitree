# MuJoCo 滑雪物理环境 V1：雪面、雪板与场地设计

版本：0.1（设计草案）  
日期：2026-09-07  
项目：Unitree G1 滑雪 PR showcase  
建议存放位置：`docs/ski-physics-environment-v1.md`

> 本文规定第一版仿真环境的建模方案与验收边界，不代表实现已经完成或经过实测标定。所有建议初值均为数值实验起点，不是赛事规格或已验证的雪材质参数。

## 1. 目标与范围

构建可用于控制开发和仿真训练的 MuJoCo 滑雪环境，逐步支持：

1. 均一斜面上的直滑、侧滑、制动、连续转弯与刻滑机制验证。
2. 猫跳（moguls）场地中的地形跟随、吸收冲击、接触切换和转向。
3. 自由式场地中的助滑、起跳、腾空、落地和滑出。

第一版采用“固定均质雪面＋低维柔性雪板＋分布式接触”。保留决定动作是否成立的动力学，不模拟雪颗粒、真实雪层断裂或完整复合材料结构。

环境必须让 G 通过关节执行器影响运动。不得用隐含的根节点牵引、指定转弯轨迹或空中额外驱动力，替代应由接触和关节运动产生的动力学。单板验证夹具可施加已记录的外载，但不能作为最终机器人控制能力的证据。

没有专业动作数据集不意味着不能进行仿真训练。环境设计与新模型的角色分开：新模型可以生成程序、规划动作或参与运行时控制；本文不预先决定控制算法，也不将仿真训练称为 zero-shot。

## 2. 关键决策

| 项目 | V1 决策 | 理由与边界 |
| --- | --- | --- |
| 雪材质 | 固定、均质的压实雪等效参数 | 先隔离地形与控制问题；不宣称真实雪况还原 |
| 地形 | 平面与静态高度场 | 同一接触模型用于三类场地 |
| 雪板外观 | 双翘、带侧切的完整 mesh | 仅负责视觉，禁用该外观 mesh 的雪面碰撞 |
| 雪板力学 | 少量刚性段＋被动弹性关节 | 表达受载弯曲，保留质量、惯量与弹性能 |
| 雪板接触 | 板底及左右刃分布式接触代理 | 表达载荷分布与接触力矩，避免单点支撑 |
| 雪面法向支撑 | MuJoCo 原生软接触 | V1 不叠加第二套法向弹簧 |
| 切向作用 | 原生各向异性摩擦接触，显式管理接触坐标 | 支持静态约束反力与有限滑动；不重复添加自定义摩擦 |
| 板刃作用 | 用随立刃、接触位置和载荷变化的有限等效抓地能力近似 | 不模拟真实切雪过程；必须允许失抓和侧滑 |
| 雪痕与飞雪 | 视觉效果 | 不改变高度场或产生额外动力 |
| 实现平台 | 先验证原生 CPU MuJoCo | MJX／其他批量后端另做兼容性评估 |

高横向摩擦仅表示较强防侧滑能力，不能单独证明刻滑成立。刻滑还要求有效侧切、受载弯曲、局部刃线方向及分布反力产生合理轨迹。

## 3. 坐标、单位与统一接口

### 3.1 坐标约定

- 世界系采用米、秒、千克、牛顿、弧度；Z 轴向上，重力为 `(0, 0, -9.81)`。
- 场地 X 轴沿主下坡方向，Y 轴横跨雪道。均一斜面可写为 `z = z0 - x * tan(alpha)`。
- 雪板局部 X 轴从板尾指向板头，局部 Y 轴横板，局部 Z 轴朝板面上方。
- 所有状态、载荷及速度都注明坐标系；接触速度使用作用点速度，包含刚体角速度贡献。

对接触位置的雪面单位法向 n、雪板局部长度方向 a，定义：

```text
t = normalize(a - dot(a, n) * n)   # 雪面内沿板方向
b = cross(n, t)                    # 雪面内横板方向
v_parallel = dot(v_relative, t)
v_lateral  = dot(v_relative, b)
```

刻滑接触应使用对应刃段的局部刃线方向；不能始终用整块雪板中心轴替代所有接触点的方向。当投影长度接近零时，使用稳定退化处理并标记异常姿态，禁止除零或产生随机方向。

立刃角取雪板相对局部雪面的有符号侧倾角，绕局部沿板方向计算。不能直接将两个法向的夹角作为立刃角，否则跳台上的俯仰也会被错误解释为立刃。

### 3.2 地形接口

所有场地提供同一组信息：

```text
height(x, y) -> z
normal(x, y) -> unit normal
region(x, y) -> approach / takeoff / flight_gap / landing / runout / moguls
material(x, y) -> snow material id
```

物理碰撞与查询接口必须源于同一份地形数据。解析曲面的导数可辅助设计，但不能把解析曲面法向直接当作离散碰撞面的真实法向而忽略网格误差。接触求解使用实际碰撞法向。

## 4. 雪面建模简化

### 4.1 保留与省略

保留局部高度、坡度、曲率、有限接触顺应性、方向相关的切向承载及能量耗散。省略温度、水膜、蜡层、雪粒流动、压实历史和永久雪沟。

“均质”指材质参数空间一致，不要求场地处处平直。猫跳与跳台仍使用相同雪材质，只改变几何。

### 4.2 法向接触

V1 由 MuJoCo 原生接触负责法向力，不再额外施加 `k * penetration` 法向弹簧。软接触中的穿透是数值顺应性的结果，不能未经标定就解释为真实雪板入雪深度。

调节接触软硬度时同时检查静态沉降、滑行、落地冲量和时间步收敛。禁止为了“看起来不穿模”无限提高刚度，或通过极软接触掩盖不合理落地。

### 4.3 切向接触与抓刃

用有限的沿板系数 `mu_parallel` 与横板系数 `mu_lateral` 表示等效作用。椭圆摩擦锥下，两方向的承载存在耦合，不能同时独立取满各自上限。

概念上的纯横向容量为：

```text
abs(F_lateral) <= mu_lateral * N
```

这是容量约束，不是主动施力命令。没有法向支撑时，不应存在相应的切向抓地力。

板底维持较弱横向阻力；左右刃接触根据立刃状态平滑改变抓地能力。例如：

```text
u = clamp((abs(edge_angle) - theta_on) / (theta_full - theta_on), 0, 1)
activation = u*u*(3 - 2*u)
mu_lateral = mu_flat + activation * (mu_edge - mu_flat)
```

该式只是可调的降阶模型。还需按接触归属确认是承载刃，并依靠实际接触反力分配载荷；不能让抬起的一侧刃因角度较大而产生作用。`theta_on`、`theta_full` 均通过单板实验确定。

初版不采用瞬时“板底模式／板刃模式”硬切换，不默认板刃沿长度方向一定比板底更滑。`0.8f` 等差异无标定依据时不引入。

### 4.4 参数初值与校准规则

| 参数 | 开发扫描建议 | 约束 |
| --- | --- | --- |
| `mu_parallel` | 可从 0.02、0.05、0.10 做敏感性扫描 | 仅为数值试验点，不代表所有雪况 |
| `mu_flat` | 可先取 `mu_parallel` 的 1–2 倍 | 必须能连续侧滑；不能近似焊接地面 |
| `mu_edge` | 可先扫描 0.3、0.6、1.0、1.5 | 与目标载荷和转弯半径联合检查 |
| 立刃激活区间 | 先扫多个区间，不固定为真实阈值 | 放平、立刃、换刃过程中连续 |
| 接触软硬度 | 从模型稳定设置起逐步调节 | 以沉降与冲量收敛验收 |

不得仅写 `10f` 而不记录基准系数。也不得仅因机器人更容易成功就提高摩擦上限。

平地稳态转弯可用 `v² / (R*g)` 检查横向力与法向力的量级；斜坡需要进一步计入重力在雪面内的分量及动态载荷。该关系用于检查，不用于强制生成轨迹。

## 5. 雪板建模

### 5.1 几何参数

至少分别记录板长、板头／板腰／板尾宽度、厚度、前后翘起、初始拱度、固定器位置、质量和惯量。侧切是俯视宽度变化，不能用前后翘曲代替。

第一版使用一套可配置双翘板几何，方便前滑、倒滑和基础自由式演示。不同项目若更换侧切或刚度，必须作为显式配置版本，不在同一回合中隐藏切换。

G1 的具体型号、关节自由度、限位、执行器上限及足部坐标以项目实际 MJCF 为准。不得从机器人名称推断其可实现的人体动作范围。

### 5.2 结构模型

每块雪板先采用约 7 段（可在 5–9 段内调整），中央段连接固定器，两侧向板头和板尾延伸。段间以被动 hinge 的刚度与阻尼近似沿板长分布的弯曲。V1 可先限制扭转变形，但必须记录该简化对刃角分布的影响。

可用分段梁的量级关系 `k_theta ~ EI / segment_length` 构造初始关节刚度，再以静态挠度校准。该量级关系不代替实际边界条件下的梁验证。改变段数时重算刚度、质量和惯量，不能原样复制每段参数。

固定器初版与足部刚性连接，不模拟脱落和真实雪靴柔性。不能因此给机器人额外增加主动关节。雪板弹性关节无执行器，允许储存与释放弹性能，阻尼只耗散能量。

### 5.3 接触代理

- 使用按板宽和侧切布置的薄凸块、小圆角接触体或经验证的离散刃段。
- 左右刃沿板长分布，接触代理尺寸和位置必须与视觉形状一致到可接受误差。
- 板底代理用于放平支撑；避免板底与板刃代理重叠造成重复支撑或错误载荷分配。
- 接触点速度及施力位置保留板头、板腰、板尾的差异，由力臂自然产生转动效果。
- 局部刃线不能简单由所有接触点共享同一个世界方向。
- 检查凸包、圆角半径和接触 margin，防止视觉上未接雪却已产生强抓地。

MuJoCo 普通 mesh 碰撞使用凸包，完整雪板 mesh 的凹入侧切可能被填平。因此，外观 mesh 不作为唯一的物理碰撞表示。[1]

### 5.4 刻滑能力边界

满足“横向不滑”不能作为刻滑验收。必须在不直接施加偏航驱动力的受控单板实验中，检查加载与立刃后是否形成方向正确、连续且随载荷和角度合理变化的转弯响应。

若分段模型只能靠主动扭板完成转弯，应标注为侧滑转向或降阶滑雪代理，不宣称已验证刻滑。修正顺序为：接触方向 → 侧切几何 → 弯曲与承载长度 → 载荷分布 → 横向容量。禁止首先用超高摩擦强行修补。

## 6. MuJoCo 实现约束

### 6.1 摩擦参数与接触坐标

普通 `geom friction="a b c"` 表示滑动、扭转和滚动摩擦，不表示沿板、横板和法向。显式 `contact pair` 可以设置两个切向滑动系数，但仍须验证接触切向与雪板的对齐关系。[1][2]

建议 V1 从 `condim=3` 和椭圆摩擦锥开始，只保留法向及两个切向约束；板上分布接触自然提供力矩。不要利用很大的扭转或滚动摩擦补偿错误的接触布局。

### 6.2 执行顺序

原生 CPU 路线需在碰撞生成之后、接触约束装配之前完成：

1. 识别雪板—雪面的接触，保留正确的法向与 geom 顺序。
2. 根据接触所属刃段构造正交的接触切向基。
3. 写入沿板、横板系数及连续的立刃调制。
4. 再构建并求解接触约束，推进动力学。

这是实现要求，不是已经验证的 API 调用代码。开发时必须锁定 MuJoCo 版本，检查该版本提供的碰撞／约束阶段调用及扩展路径。不得假定在 `mj_step1` 后修改 contact 就会自动重建所有相关约束；也不得让之后的完整前向调用覆盖已修改的 contact。

先用单个接触的方向旋转实验验证上述管线，再接入全模型。如果项目后端不支持这个插入点，应重新确定接触实现路线，不可静默改为世界系固定摩擦。

### 6.3 备选自定义接触路线

仅在原生路线无法满足方向管理或后端需求时切换。切换前单独设计和验证法向／切向求解、历史状态、积分稳定性和能量边界。

`F = -Fmax * tanh(v / epsilon)` 可近似滑动阻力，但零速度下不提供静态约束反力，不能单独承担无侧滑刻滑。若采用切向弹性位移模型，要处理状态在接触坐标旋转、离地及新接触时的运输与重置，并限制储能和滑移容量。

原生与自定义作用不得重复计算同一方向的力。不能以未经检查的上一时间步法向载荷驱动当前切向力，并把它当作严格耦合求解。

## 7. 场地 A：均一斜面

### 7.1 几何与阶段

第一阶段使用无限平面排除边界问题，再扩展为有限雪道与缓坡滑出区。不要让平面在高度场下重复承载同一块雪面。

```text
z(x, y) = z0 - x * tan(alpha)
```

开发坡度可从 5°、10°、15° 逐级增加。长度、宽度根据实际初速度、转弯半径和停止距离确定；这些坡度不是赛事场地要求。

### 7.2 任务与验收

- 直滑：速度与重力、纵向阻力相容。
- 横滑：存在有限阻力，不出现不合理瞬间停住。
- 放平／立刃：抓地平滑变化，左右换刃无脉冲式锁死。
- 连续转弯：记录速度、实际轨迹曲率、侧滑角、刃角及每板载荷。
- 出界：终止或标记失败，不用隐形墙帮助转弯。

先验证固定材质下的行为，再讨论材质随机化。相同配置必须可重放。

## 8. 场地 B：猫跳（Moguls）

### 8.1 几何生成

用基础斜坡叠加错列的平滑凸包，凸包之间自然形成沟谷。建议使用具有有限支撑范围的平滑函数：

```text
q_j = ((x-x_j)/rx_j)^2 + ((y-y_j)/ry_j)^2
bump_j = A_j * (1-q_j)^3, if q_j < 1; otherwise 0
z(x, y) = z_base(x, y) + sum_j bump_j
```

该函数在支撑边界处高度、一阶及二阶导数连续，便于控制进入、离开凸包的曲率变化。叠加后仍需检查总坡度、最小曲率半径、重叠峰值和沟谷宽度。

沿下坡方向按行布置凸包，相邻行横向错开；提供幅值 A、纵横半径、行距、列距、错列偏移和随机种子。入口与出口用平滑包络衰减到基础坡面。

### 8.2 难度递进

1. 单个低凸包：检查板头接雪、跨越和重新落地。
2. 一列宽缓凸包：检查腿部伸缩与周期载荷。
3. 规则错列猫跳：加入横向选线与连续转向。
4. 有限扰动：改变高度、间距和偏移，检验泛化。

初始凸包高度可从 0.10–0.25 m 试起，并根据 G1 关节行程、板长及接触状态调整；这只是低难度开发场景。不得将提高凸包高度等同于真实竞赛难度标定。

### 8.3 特别要求

- 雪板不同段使用各自接触法向；不能整板共享一个雪面法向。
- 允许局部或整板离地，不用吸附力保持贴地。
- 地形必须有足够横向宽度与退出区域。
- 记录峰值法向载荷、离地时长、板头／板尾碰撞、关节限位触发和线路完成情况。
- 若失败来自地形离散棱角，应提高几何分辨率，而不是无限增大接触软度。

## 9. 场地 C：自由式助滑、跳台与落地

### 9.1 V1 范围

首先实现单个 kicker／小型 tabletop 类型场地，覆盖助滑、起跳、腾空、着陆和滑出。这里的“自由式”不意味着 V1 同时覆盖全部大跳台、坡面障碍和 U 型场地，也不包含所有旋转圈数或抓板动作。

### 9.2 场地分区

| 分区 | 设计要求 | 主要参数 |
| --- | --- | --- |
| 助滑区 | 平滑获得目标起跳速度，具有足够长度 | 坡度、长度、入口状态 |
| 起跳过渡 | 从助滑坡连续过渡到出唇切线 | 过渡长度、曲率、出唇角 |
| 台唇／台面 | 明确真实离地位置和几何边缘 | 台唇位置、高度、台面长度 |
| 飞越区 | 几何与碰撞一致，失误可碰撞或跌落 | 台面或空隙形状 |
| 落地区 | 着陆坡与预期速度方向相容 | 落地坡度、长度、横向宽度 |
| 滑出区 | 平滑减小坡度，提供恢复与制动空间 | 过渡半径、长度 |

起跳过渡和落地接续建议用分段五次多项式或样条，优先约束位置、切线和曲率连续。真实台唇边缘可存在几何不连续，但必须是有意设计，不能由粗网格意外生成。

### 9.3 先用弹道筛选场地

设计阶段可暂忽略空气阻力，用质心近似：

```text
x(t) = x0 + vx0*t
z(t) = z0 + vz0*t - 0.5*g*t*t
```

由轨迹与落地区的交点估计可达范围，并比较落地前速度与当地坡面切线。该估计仅用于筛除明显不合理的跳台组合；完整仿真需要考虑身体姿态、板长、起跳接触和实际首次接触点。

第一阶段由小高度、低速度、无旋转跳跃开始，再逐步增加动作。起跳速度、出唇角、落地位置和落地坡度必须联合设计。

### 9.4 动力学要求

- 离地后的雪面接触力为零；角动量变化来自明确的外力矩。
- 姿态改变可以重新分配惯量和身体角速度，不能凭空创造整体角动量。
- V1 无风，可先关闭空气阻力；若高速轨迹对阻力敏感，再加入有记录参数的模型。
- 落地不能只检查是否站住，还要检查冲量、穿透、关节和执行器限幅、反弹及滑出。
- 前滑、倒滑均使用真实雪板几何和同一接触机制，不在切换方向时更改物理规则。

### 9.5 后续扩展

| 扩展场景 | 额外工作 |
| --- | --- |
| 多跳台线路 | 前一跳滑出速度与下一跳入口条件耦合 |
| U 型场地 | 横向大曲率、壁面切换、网格与法向精度；近竖直结构需重新评估高度场表示 |
| 复杂坡面障碍 | 雪以外材质、窄接触、障碍物碰撞与不同摩擦规则 |
| 带挑檐或悬空结构 | 单值高度场不能表示；采用独立碰撞几何 |

## 10. 数值设置与地形精度

- 锁定 MuJoCo 版本、求解器、积分器、摩擦锥、容差和迭代上限，并随每次实验保存。
- 可从 0.5–1 ms 物理时间步开始评估；控制周期独立设置。该范围不是稳定性保证。
- 采用更小时间步复核落地、换刃和高载荷转弯，避免只验证平稳直滑。
- 地形网格分辨率根据最小曲率半径、板长和接触代理尺寸确定，同时检查高度误差和法向误差。
- 不仅检查“一步位移小于网格尺寸”，还要检查薄板刃、高速碰撞及几何边界是否被漏检。
- 地形边缘、分块接缝和坡度突变必须纳入检查。
- 增加接触点或雪板分段后，若轨迹显著变化，继续校准离散模型，不能将当前结果视为已收敛。

## 11. 验证与验收

先在独立单板夹具上验证环境，再连接 G1。夹具规定载荷、姿态或初速度时，应记录约束反力和外部做功；存在姿态夹持的试验不能宣称完全自由演化。

| 测试 | 操作 | 必须观察的结果 |
| --- | --- | --- |
| 静载挠度 | 分级加载与卸载 | 变形方向正确、无残余主动驱动力 |
| 方向旋转 | 水平面上将雪板旋转 90° | 高低阻方向随板旋转，不固定在世界系 |
| 直滑 | 设置坡度及初速度 | 加速度与重力、耗散相容，无横向漂移偏置 |
| 侧滑 | 放平并给予横向速度 | 有限且连续耗散，不瞬间锁死 |
| 立刃／换刃 | 平滑改变侧倾与载荷 | 抓地连续、左右响应基本对称 |
| 刻滑机制 | 受控加载、允许偏航自由演化 | 有合理转弯响应，不能依赖直接偏航驱动 |
| 离地 | 抬板或经过小跳台 | 所有雪面作用消失，无吸附 |
| 单凸包 | 跨越低凸包 | 多段接触与重新落地合理 |
| 小跳落地 | 无旋转、低难度跳跃 | 无穿透逃逸、无异常弹飞、可重复 |
| 能量检查 | 统计外功与机械能 | 无持续无来源的能量增长 |
| 离散收敛 | 时间步减半、地形与分段加密 | 核心指标变化进入预设容差 |

能量检查包含平动、转动、重力势能和雪板弹性势能，并单独统计执行器及夹具外功。不能把正常释放的弹性能误判为接触注能。

建议在开发验收前预先约定数值容差，例如稳态速度和转弯半径变化小于 5%、落地总冲量变化小于 10%；这是工程收敛目标，不是与真实滑雪误差的声明。峰值力对步长和接触模型更敏感，须单独报告。

每个回合至少记录机器人及雪板状态、接触点与坐标基、每点法向／切向力、刃角、侧滑速度、轨迹曲率、执行器限幅、求解器异常和完整配置标识。随机场地保存种子及生成结果。

## 12. 实施顺序与交付边界

| 阶段 | 交付物 | 通过条件 |
| --- | --- | --- |
| P0 | 单板＋均一斜面＋正确方向摩擦 | 直滑、侧滑、90°方向旋转测试通过 |
| P1 | 低维柔性板＋分布接触＋立刃调制 | 静载、换刃、刻滑机制与能量检查通过 |
| P2 | G1＋双板＋基础斜面任务 | 自由基座、真实限幅下可滑行与基础转向 |
| P3 | 单凸包、规则猫跳 | 接触切换与低难度线路通过 |
| P4 | 小跳台及落地区 | 起跳、腾空、着陆、滑出完整闭环 |
| P5 | 更复杂场地与动作 | 在已冻结物理版本上扩展控制和展示 |

P3 与 P4 的优先级可按展示主镜头调整。环境冻结后，不得为使某个动作成功而无记录更改摩擦或接触参数。参数改动应重跑相关基线。

本版验收不包括：赛级雪体材料准确性、真实 G1 可迁移性、谷爱凌动作逐帧精确复现、任意场地泛化或完全无训练的竞技动作能力。展示素材应说明仿真、训练、规划及程序生成各自参与的位置。

## 13. 实现前待确认

1. 项目使用的 G1 MJCF 版本、质量分布、执行器与足部安装约定。
2. 新模型负责开发控制代码，还是运行时输出动作；是否允许 RL 和轨迹优化。
3. 优先展示的动作、目标时长、允许准备时间与计算预算。
4. 目标 MuJoCo 后端是否支持接触坐标和参数更新的执行时机。
5. 雪板几何、质量、刚度采用哪些公开资料或明确的工程假设。

这些问题影响控制与实现细节，但不阻止先完成 P0 的单板物理验证。

## 14. 参考依据

以下资料支持建模机制与引擎约束，不代表本文建议初值获得文献标定。此前讨论已核对相关页面；实际开发应保存与锁定版本对应的文档。

1. [MuJoCo XML Reference：mesh、摩擦、接触和高度场](https://mujoco.readthedocs.io/en/latest/XMLreference.html)。普通 mesh 碰撞使用凸包；geom 与 pair 的摩擦参数语义不同。
2. [MuJoCo Modeling：Contact parameters](https://mujoco.readthedocs.io/en/latest/modeling.html)。说明显式接触对中的各向异性摩擦，以及接触切向坐标的限制。
3. [MuJoCo Computation](https://mujoco.readthedocs.io/en/stable/computation/index.html)。接触约束、摩擦锥与求解机制。
4. [Calculation of the contact pressure between ski and snow during a carved turn in Alpine skiing](https://onlinelibrary.wiley.com/doi/10.1111/j.1600-0838.2009.00956.x)。采用梁模型及雪的压入、剪切作用，说明载荷、立刃与接触压力的重要性。
5. [Biodynamic Analysis of Alpine Skiing with a Skier–Ski–Snow Interaction Model](https://arxiv.org/pdf/2411.08056)。采用均质斜坡、柔性雪板和离散接触，并使用实测数据校准；可借鉴分层建模方法，不能直接外推为竞技自由式验证。
6. [MuJoCo Menagerie：Unitree G1](https://github.com/google-deepmind/mujoco_menagerie/tree/main/unitree_G1)。机器人模型候选来源；具体物理参数以项目实际导入版本为准。
